**Highlights:** Customer-level predictions, model evaluation, interactive visualizations, and data drift analysis.

🌐 [Live Demo](https://psebtasktelcocustomerchurnpredictionapp-mhnb66quufw4nyhngar7vf.streamlit.app/)
